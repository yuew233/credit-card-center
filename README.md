# 信用卡中心

开源信用卡管理工具：跟踪各卡的报销额度、开卡奖励间隔、积分转分和“刷哪张”。

纯前端单页应用（Vite + React + TypeScript），**没有后端，不联网，所有数据只存在你的浏览器 localStorage 里**，不需要注册账号。

## 功能

### 报销
- 每张福利卡显示「还剩 $X · 截至日期」+ 进度条 + 周期徽章（持卡周年 / 自然年 / 自然半年 / 自然月 / 每 4 年 / 一次性）
- 只统计最近的周期：过期的福利自动隐藏，不计入总额
- 免房晚（FN）按积分档位命名，如 `35k FN` / `85k FN`；开卡第二年才开始发放（第一年显示「第二年起 · 开始日」，不计入总额）
- DoorDash 合并为一张卡（餐饮 $15 / 超市 $20 两个按钮分别记账）
- 标记已用 / 记一笔金额 / 忽略（收进底部「已忽略」区，可恢复）
- 筛选：未用 / 已用 / 全部（默认未用）+ 银行下拉

### 持卡（开卡间隔管理）
- 顶部概览：可申请 / 尚未可申请 / 待确认 / 5/24
- 每张卡默认收起为一行（银行、卡名、持有时长、红绿灯），点开看日期、年费、规则与编辑
- 间隔从**上次拿奖励日期**起算；没有该日期时按开卡日 + 3 个月估算，并标注“估算”；关卡不重置时钟
- 内置规则：Chase 蓝宝石家族 48 个月、Ink Preferred 曾经持有条款、Ink Cash / Unlimited 同一奖励家族、AmEx 一生一次、Citi 48 个月、Marriott 24 个月交叉限制等

### 转分
- 默认按伙伴分组（每个伙伴一行，列出所有能转的银行和比例），可切换按银行分组
- 每行只显示核心信息：比例、进行中奖励的绿色 `+30%` 徽章、网上常推荐路线的 ★
- 美元价值、推荐理由、到账时间、最低转分量收在行内展开详情里
- 「当前转分奖励」每条一行，过期自动进「最近结束」；积分典型价值一行小字汇总；换算器默认收起
- ⚠️ 转分不可逆

### 刷哪张
- 按消费类别分组，每类显示首选 / 次选 + 一句话理由
- 季度轮换类别是种子数据（可在应用内编辑），过期后自动降级、不再当首选；顶部轮换横幅由种子数据自动生成

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5173 即可使用。

构建静态文件（可部署到 GitHub Pages）：

```bash
npm run build
```

构建产物在 `dist/`。部署到 GitHub Pages 子路径时，把 `vite.config.ts` 里的 `base` 改成 `'/<仓库名>/'`。

## 导入自己的卡

首次打开是空的（只有通用的参考数据）。两种方式填入自己的卡：

### 方式一：导入模板 JSON（推荐）

1. 复制 `data/cards-template.json`，按格式填自己的卡：

```json
{
  "version": 1,
  "cards": [
    {
      "bank": "Chase",
      "name": "Sapphire Reserve (CSR)",
      "productId": "chase-sapphire-reserve",
      "kind": "personal",
      "status": "open",
      "openedOn": "2024-03-10",
      "lastBonusOn": "2024-06-10",
      "bonusReceived": true,
      "note": ""
    }
  ]
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `name` | 卡名（必填，最好和目录里的产品名一致） |
| `productId` | 目录里的产品 id（不知道可留空，导入时按名字匹配）；填了就会按该产品自动生成福利 |
| `bank` | 银行 |
| `kind` | `personal` 个人卡 / `business` 商业卡 |
| `status` | `open` 持有中 / `closed` 已关卡 |
| `openedOn` | 开卡日期 `YYYY-MM-DD` |
| `lastBonusOn` | 上次拿开卡奖励的日期（不知道可留空，会按开卡日估算并标注“估算”） |
| `bonusReceived` | 是否拿过该卡奖励：`true` / `false` / `null`（待确认） |
| `note` | 备注 |

2. 点页面右上角「导入模板」，上传填好的 JSON。导入时福利会按卡产品自动生成（例如 CSR 会自动带出旅行报销、The Edit、StubHub、DoorDash 等）。

### 方式二：手动添加

在「持卡」页点「＋ 添加卡片」，从目录选产品、填开卡日期即可；福利同样自动生成。

### 先看看效果

点「加载示例卡」会导入 3 张明确标注“示例”的假卡，熟悉功能后点「清空数据」再导入自己的卡。

## 数据与隐私

- 所有数据（卡片、福利、使用记录、参考数据的修改）只保存在浏览器 localStorage，**不会发送到任何服务器**。
- 换浏览器、清缓存会丢失数据，请定期点「导出备份」保存 `credit-card-center-backup.json`，需要时用「导入模板」恢复。
- 参考数据（转分比例、转分奖励、积分估值、刷卡返现）是公开信息，2026-11-18 核实；银行条款会变，请以发卡行官网为准，应用内均可编辑。

## 卡产品目录

内置产品见 `src/data/catalog.ts`（年费、福利模板、开卡间隔规则均为公开的产品信息）。想加新卡产品，往这个文件里加一项即可；参考数据在 `src/data/reference.ts`。
